Ir al Sitio Público
Aviso de Seguridad Académica: Este es un servidor HTTP/1.1 educativo sin cifrado TLS (HTTPS). La autenticación HTTP Basic transmite credenciales codificadas en Base64. Es adecuado para prácticas en localhost o red LAN de laboratorio, pero no debe exponerse a Internet público con credenciales reales.
Reinicio Manual Pendiente: Se guardaron cambios en parámetros de enlace o raíz (host, port o document_root). Para aplicarlos en el socket TCP principal, detenga el servidor con Ctrl+C y vuelva a ejecutar python main.py.

Parámetros de Enlace y Raíz Requieren Reinicio
Use 0.0.0.0 para LAN o 127.0.0.1 solo local.
Sugerido: 8080 (sin privilegios de administrador).
Carpeta raíz desde donde se sirven los recursos estáticos.
Parámetros Operativos y de Seguridad Aplicación Inmediata
Entre 1.024 B (1 KB) y 52.428.800 B (50 MB).
Entre 1 y 300 segundos por conexión.
Cada ruta debe iniciar con / y no contener ...
Si se ingresa, se almacenará únicamente su hash PBKDF2-HMAC-SHA256 con sal.
