Entorno Académico Demostrativo: Este servidor gestiona directamente sockets TCP IPv4 y analiza mensajes HTTP/1.1 sin emplear Apache, Nginx, Flask ni http.server.

Pruebas Rápidas para la Exposición

Utilice los siguientes enlaces para verificar en vivo cada requisito de la consigna y observar las entradas generadas en logs/access.log y logs/error.log:

  • 1. Solicitud GET estática (200 OK) Sirve documento HTML sobre el modelo TCP/IP y el parser HTTP.
  • 2. Directorio Protegido (401 / 200) Solicita autenticación HTTP Basic antes de entregar el recurso en /private/.
  • 3. Documento Confidencial en /private Segundo archivo dentro del directorio protegido.
  • 4. Recurso Inexistente (404 Not Found) Demuestra manejo de errores HTTP y registro en error.log.
  • 5. Prueba de Path Traversal Codificado (403 Forbidden) Intenta escapar del DocumentRoot hacia config/server.json usando %2e%2e.
  • 6. Panel Web de Administración (/admin) Consulta estado, logs y modifica parámetros validados del servidor.
